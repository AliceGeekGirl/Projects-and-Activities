Registrar contrato

Registre seu contrato para gerar um código de verificação e comprovar posteriormente que o arquivo corresponde ao registro original.

O que acontece depois?

O ProofFile calcula uma identificação do arquivo, registra essa informação e gera um código de verificação para o contrato.
